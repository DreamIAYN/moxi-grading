# 评分口径与扩展说明

## 1. 目标

系统不替代正式阅卷，而是把“阅卷人先解题、再按步骤找分”的过程结构化，输出可复核的分数与批注。每次批改必须满足：

1. 先独立核验题目与正确解法，再评价学生稿；
2. 只评价卷面已经写出的内容，不替学生补步骤；
3. 每个扣分点说明“错在哪、为什么、如何补”；
4. 分项得分之和等于总分，且落在允许档位上；
5. 若未提供评分标准，先在评分前制定评分标准并生成 PDF。

## 2. 总分与得分点

| 总分 | 得分点 | 允许分数 |
| ---: | ---: | --- |
| 50 | 10 分/点 | 0 / 10 / 20 / 30 / 40 / 50 |
| 40 | 10 分/点 | 0 / 10 / 20 / 30 / 40 |
| 21 | 3 分/点 | 0 / 3 / 6 / 9 / 12 / 15 / 18 / 21 |
| 7 | 1 分/点 | 0–7 的整数 |
| 一试第9题 | 4 分/点 | 0 / 4 / 8 / 12 / 16 |
| 一试第10、11题 | 5 分/点 | 0 / 5 / 10 / 15 / 20 |
| 一试填空 | 0 / 8 | 0 或 8（不给中间分） |

其他总分使用自定义得分点；默认 1 分/点。`server/scoring.mjs` 中的 `getScoreScheme()` 会按总分自动选择档位，后端 `snapScore()` 会把模型返回的分数吸附到最近的允许档位，保证不会出现 7/40、13/50 这类不在档位上的分数。

## 3. 题型

支持：**代数、数论、组合、几何、一试、其他**，也可以选“自动识别”。

- **组合**：常分构造与证明两个方向。只完成较简单的构造方向时，按实际贡献给部分分；经验量级为 20/50、10/40、6/21、2/7，具体由题目难度与完成度决定，不自动给一半或满分。
- **几何**：以完整证明链为主；计算未完成时，只看是否明确证出有用的几何结论。
- **数论**：素因子、整除、同余不变量等实质步骤给主要分；只举一个例子通常只给构造分。
- **代数**：真正的估计、代换、取等分析与分类讨论给主要分；例行化简易视为平凡步骤。
- **一试**：填空只给 0/8；第9题 16 分（4分/点）；第10、11题 20 分（5分/点）。

“结论是否平凡”是评分时的核心判断：直接套定义、例行变形、重复题设属于平凡步骤；真正推进结论的关键构造、引理、估计与分类讨论才给主要分。该规则同时写入评分标准生成 prompt 和评分 prompt。

## 4. 评分前生成评分标准 PDF

当用户没有粘贴/上传官方答案或评分细则时，`/api/grade` 会按以下顺序执行：

1. **官方模板**：若选择的是 2026 A 官方模板，直接使用模板中的评分点、档位与部分分规则；
2. **模型制定**：否则调用模型，先按学生解答重建实际路线，再拆解评分点、允许档位、部分分规则，输出 JSON；
3. **兜底模板**：模型失败时使用按总分与题型生成的通用评分框架，并在结果中提示；
4. **生成 PDF**：用 XeLaTeX 生成评分标准 PDF，保存到 `data/rubrics/<rubricId>/`；
5. **正式评分**：把评分标准连同题目、手写稿交给评分模型，才开始给分。

评分标准 PDF 包含：题型、总分、得分点、允许档位、评分点与中间档、部分分/不叠加规则、“结论是否平凡”的判断说明。结果页「评分依据」中可下载该 PDF。

## 4.3 CMO 严格 3 分制

CMO 单题固定满分 21 分，严格按 3 分一个得分点：允许档位只有 0、3、6、9、12、15、18、21。评分点满分和锚点也必须是 3 的整数倍；不会出现 1 分、2 分或 1.5 分。

## 4.4 实质给分门禁

评分标准与阅卷 prompt 都加入了最高优先级的实质门禁：

- 只写最终答案、猜测或结论，没有可核验推导：**0 分**（填空除外）。
- 只有正确思路、方法名、开头、设元或框架，但没有得到任何正确结论：**0 分**。
- 结论错误，且没有独立成立的实质中间结论：**0 分**。
- 步骤多、篇幅长、书写认真、态度好，都不构成得分理由。
- 只有形成可核验的正确子结论、完整方向或完整构造，才可给对应评分点的分。

例外：正确完成充分性/必要性的一支、组合的完整构造并验证、几何中完整证明的引理，属于实质进展。官方模板中明确列出的中间结论按其档位给分，但不额外给“思路分”“方法分”。

自动阅卷会输出 `substantiveGate`；未通过时总分强制为 0，报告显示“未通过实质给分门禁”。整卷模式逐题输出 `substantive`，未通过的题记 0 分。

## 4.5 按学生路线制定评分标准

批改前**不独立做题、不生成参考解**。先逐页读取学生解答，按学生实际写出的思路重建路线，再制定评分标准：

- 学生路线正确时，按学生的关键步骤、子结论与构造设评分点；
- 学生路线错误或走偏时，不另起正确解法替换；只核验学生已经写出的步骤，成立的实质子结论可给分，错误步骤 0 分；
- 每道题记录 `studentRoute`：路线状态、按学生思路重述、成立步骤、逐评分点映射；
- 评分时只按学生实际路线给分，不因与“标准解法”不同而扣分。

## 6. 整卷模式

选择整卷模板并打开「整卷模式」后：

- `questions` 定义每道题的题号、题型、满分、得分单位与给分方式；
- 评分模型必须逐题输出 `questions`，不能合并或漏题；
- 后端逐题吸附分数、求和得到总分；
- 网页显示分题得分表，PDF 使用可跨页的 `longtable`；
- 一试整卷 120 分；加试整卷 180 分。

## 7. 数据结构

```json
{
  "score": 10,
  "criteria": [
    { "name": "代数变形", "max": 4, "awarded": 4, "reason": "..." }
  ],
  "questions": [
    { "no": "9", "type": "解答", "score": 12, "topic": "代数", "comment": "..." }
  ],
  "annotations": [
    {
      "page": 1,
      "x": 0.12, "y": 0.20, "w": 0.45, "h": 0.06,
      "severity": "warning",
      "title": "变量范围未说明",
      "comment": "...",
      "suggestion": "...",
      "rubric": "变量代换与范围",
      "question": "9",
      "delta": -1
    }
  ]
}
```

- `criteria` 是单题分数来源；整卷模式以 `questions` 为分数来源。
- `annotations` 坐标相对解答页左上角；`w/h=0` 表示无法定位，只在文字清单保留。
- `delta` 只作解释，不参与总分计算。

## 8. 新增总体标准

### 页面内新建（推荐）

1. 打开「评分标准」→「新建标准」；
2. 填写名称、题型、适用范围、得分点单位；
3. 添加评分项与满分，系统自动合计；
4. 保存并「设为默认」；
5. 下次批改会自动带入该标准。

自定义标准保存在浏览器 `localStorage`。重要标准建议同时写入 `src/lib.ts` 的 `BUILTIN_RUBRICS` 并提交版本库。

### 写入内置标准

在 `src/lib.ts` 的 `BUILTIN_RUBRICS` 增加一项：

```ts
{
  id: 'my-standard',
  name: '某某考试 · 单题',
  scope: '适用范围',
  total: 20,
  unit: 5,
  category: 'algebra',
  mode: 'standard',
  description: '给分原则',
  items: [
    { name: '思路', max: 5, description: '...' },
    { name: '论证', max: 10, description: '...' },
    { name: '书写', max: 5, description: '...' },
  ],
  builtin: true,
}
```

`total` 应等于各 `items.max` 之和；`unit` 必须与总分档位一致。

## 9. 复核与限制

- 批注坐标由视觉模型估算，可能偏移；教师应以文字批注和原卷为准。
- 自动生成的评分标准是“评分前的结构化方案”，正式考试仍以官方细则为准。
- 当前没有拖拽改框/手动改分的复核界面；正式归档前建议人工核对分数。
- PDF 由 XeLaTeX 生成，文件缓存在 `data/jobs/<id>/report.pdf`。
